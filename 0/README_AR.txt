دليل فعاليات الجامعة الافتراضية السورية — BWP401
==================================================

محتويات المشروع
- index.html: الصفحة الرئيسية والفعاليات البارزة والتصنيفات.
- events.html: قائمة الفعاليات مع البحث والفلترة حسب التصنيف والفترة والتاريخ المحدد والمكان.
- event.html: تفاصيل الفعالية، صورة، خريطة توضيحية، فعاليات ذات صلة، تقويم ومشاركة وحجز تجريبي.
- about.html: عن الدليل، الرؤية والرسالة والفريق ومعايير النشر.
- contact.html: نموذج تواصل مع تحقق JavaScript ورسائل نجاح/خطأ.
- assets/css/styles.css: الهوية البصرية والتصميم المتجاوب.
- assets/js/main.js: بيانات الفعاليات والتفاعلات.
- assets/img/: صور الفعاليات، صورة رمزية للفريق، وخريطة SVG ثابتة توضيحية.

بيانات الفعاليات
- يتضمن المشروع الفعاليات الست الواردة في ملف BWP401_Event_Guide المرفق.
- ورقة الوظيفة توضح أن بيانات الفعاليات في هذا النموذج توضيحية وليست إعلانات رسمية.
- مدة الفعاليات غير محددة في الملف، لذلك لا يعرض الموقع مدة مفترضة.

معلومات الفريق
- تظهر أسماء المشاركين وأرقامهم الجامعية وأدوارهم في الصفحة الرئيسية وصفحة «عن الدليل».
- أُضيفت أسماء الفريق وأرقامهم الجامعية إلى البطاقات؛ راجعوا دقتها قبل رفع ZIP أو نشر الموقع.
- صور الفريق رمزية عامة وليست صوراً شخصية. يمكن استبدالها بصور المشاركين إذا طُلبت صور فعلية.

التشغيل والتسليم
1. افتح index.html في المتصفح ثم جرّب روابط الصفحات والبحث والفلاتر ونموذج التواصل.
2. Bootstrap والخطوط وصور الفعاليات تُحمّل عبر الإنترنت من CDN ومصادر صور مجانية.
3. فلترة الفعاليات تعمل بالكلمات والتصنيف والفترة والتاريخ المحدد والمكان. نافذة الحجز تجريبية ولا تحفظ البيانات.
4. للاستضافة المجانية، ارفع محتويات المجلد إلى مستودع GitHub عام، ثم فعّل Settings > Pages > Deploy from a branch > main > /(root).
5. استخدم رابط الاستضافة الفعلي الذي يظهر في GitHub Pages، ولا تخمّنه قبل النشر.
6. أرسل رسالة واحدة إلى t_balkhatib@svuonline.org بعنوان BWP401 HW؛ أدرج IDs جميع أعضاء الفريق ورابط الموقع.
7. ارفع ZIP الموقع فقط على Moodle، من دون تقرير.

ملاحظات
- نموذج التواصل يتحقق من البيانات في المتصفح ويعرض رسالة نجاح أو خطأ، لكنه لا يرسل بريداً إلى خادم.
- الخريطة المرفقة رسم ثابت توضيحي وليست دليلاً جغرافياً دقيقاً؛ ملف الفعاليات لا يذكر عناوين تفصيلية.
- يحتاج Bootstrap والخط والصور إلى اتصال بالإنترنت.

المشروع مبني باستخدام HTML وCSS وJavaScript وBootstrap 5، ويدعم اللغة العربية واتجاه RTL.
